# ST专用

macOS 截图翻译工具：框选屏幕，将多语言文字译成简体中文，在原图浮窗中查看。

[官网与使用说明](https://st-screen-translator.marywhyte19880720.chatgpt.site/) · [下载](https://github.com/mary113344daa-lab/st-screen-translator/releases)

## 1.4.3（build 10）

- 按 **F4**（或你设置的截图快捷键）直接拖框，松开后翻译；需要 ST专用具有有效的 macOS 屏幕录制权限。
- 权限暂不可用时，可用系统快捷键先截图到剪贴板，再在 ST 小窗或菜单栏点 **“翻译剪贴板截图”**，直接进入翻译，不弹出主界面。
- 保留在线服务限流或额度不足时自动尝试系统翻译、等待期内新截图直接走系统翻译，以及常见中文与英文／外文混排处理。自动切换不修改原有服务偏好。

## 安装与使用

支持 **macOS 15+、Apple Silicon 和 Intel Mac**。下载 ZIP，解压后将 `ST专用.app` 拖到“应用程序”，再打开。已有用户可在软件内检查更新。

1. 在“翻译设置”选择系统翻译，或填写自己的在线翻译服务地址、模型和 API Key。系统翻译无需 Key，首次使用某个语种仍可能需要确认并下载语言包。
2. 按 **F4** 直接拖框。快捷键可在设置中选择 F1–F8，另支持 Option + Shift + T；若功能键触发系统功能，请同时按 Fn。
3. 在译文浮窗中查看结果，可切换原图、置顶、复制图片或保存 PNG。Esc 关闭浮窗并取消当前任务。

### 权限暂不可用时

先按 **Control + Shift + Command + 4**，在系统框选需要翻译的区域，将截图放入剪贴板。随后在 **ST 小窗或菜单栏**点击 **“翻译剪贴板截图”**。此流程不打开主界面，也无需在 ST 中再次框选。

如需继续使用 F4 直接截图，请在 macOS 系统设置中确认 ST专用的屏幕录制权限有效。剪贴板方式是备用入口，不会修复或重置系统权限。

## 数据与费用

截图在本机识别，在线翻译仅发送识别文字，不上传截图。每位用户使用自己的 API Key，保存在本机钥匙串；在线服务可能按用量收费。自动转系统翻译不会撤回已经发出的在线请求，也不会增加服务商额度。自动更新通过 GitHub 检查和下载版本。

翻译结果受图片清晰度、识别结果、支持语种及模型影响；重要内容请核对原文。问题反馈：[Issues](https://github.com/mary113344daa-lab/st-screen-translator/issues)。第三方许可见 [THIRD-PARTY-NOTICES.txt](THIRD-PARTY-NOTICES.txt)。
