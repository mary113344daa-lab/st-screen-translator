# ST专用

macOS 截图翻译工具：按快捷键框选屏幕，将多语言文字翻译成简体中文，并在原图浮窗中查看。

## 1.4.1 改进

- 在线服务遇到限流、额度不足、消费或用量上限、暂时不可用或连接失败时，自动尝试系统翻译当前内容，无需再点击切换按钮，也无需重新截图。
- 在同一在线配置的等待期内，新截图直接使用系统翻译，遵守服务商要求的等待时间，不重复请求被限制的在线服务。
- 改善常见中文与英文／外文混排的系统翻译处理，减少整段被当作中文而跳过的情况，并保留文字与原图区域的对应关系。
- 自动切换只用于当前任务，保留原有在线服务、模型和密钥偏好。系统翻译也未能完成时，会显示原因并等待手动处理，不在两种服务间循环重试。
- 延续 1.4.0 的错误分类、当前内容重试、F1–F8 快捷键、截图小窗、原图覆盖、置顶、复制／保存 PNG、连接复用和短期缓存。

系统翻译无需 API Key；首次使用某个语种时，仍可能需要确认并下载语言包。

## 开始使用

1. 打开“翻译设置”。在线翻译可直接填写自己的 OpenAI Key，或配置其他兼容服务的地址、模型和 Key；也可以选择系统翻译作为默认服务。
2. 默认按 **F1** 截图，可在设置中任选 **F1–F8**，另有 Option + Shift + T。若按键触发亮度、音量等功能，请同时按 Fn，或在 macOS 键盘设置中启用标准功能键。
3. 首次截图按系统提示授予屏幕录制权限。框选后，译文会覆盖到截图对应位置。适用的在线服务错误会自动转系统翻译；首次使用系统语言包时，请按系统提示完成下载。
4. 浮窗支持原图切换、置顶、重新截图、文字对照、复制图片和保存 PNG。Esc 关闭浮窗并取消尚未完成的截图任务。

也可导入图片，或按 Command + Shift + V 粘贴图片／文字翻译。复杂表格、竖排、模糊小字建议分区域截图；复杂照片背景的覆盖效果可能留下色块。混排处理针对常见情况，翻译结果仍需结合原文核对。

## 自动恢复与等待

自动转系统翻译不会修改默认服务设置，也不会增加在线账户的余额或额度。在线错误仍按临时限流、可用额度不足、账户／组织／项目上限和未知 429 区分；服务未说明原因时，不猜测余额问题。

有等待期限时，软件会保留该期限，同一在线配置在等待期内直接使用系统翻译。若系统翻译也失败，可在小窗查看原因并手动重试系统翻译，或打开设置处理服务配置。密钥无效、服务地址错误等配置问题仍需按提示修正。

## 自动更新

从 1.3.0 开始，软件默认每天检查一次更新，菜单栏和设置中也可手动检查。在设置中可开启“自动下载并安装更新”，或关闭自动检查。

更新订阅和安装包均进行签名校验。安装包只包含公开校验密钥。1.2 及更早的“译窗”需要手动安装一次新版本，以后沿用此更新频道。

## 数据与费用

- 截图在本机识别；在线翻译只将识别文字发送给用户配置的翻译服务，不上传截图。
- 每位用户自行填写密钥，密钥保存在自己的 macOS 钥匙串中。在线服务可能按使用量收费；自动切换系统翻译不会撤回已经发出的在线请求。
- 系统翻译无需 API Key，首次下载语言包需要联网。
- 翻译历史仅在本次运行期间保存，退出后清除。
- 自动更新会连接 GitHub 检查版本及下载文件，已关闭系统画像上传。

翻译结果受截图清晰度、识别准确度、系统支持语种和所选模型影响。重要内容请核对原文。

## 速度与多人使用

复用在线连接；完整译文短期内存缓存（5 分钟、64 项、2 MiB）；系统翻译按语言批量处理。保留高精度识别和现有模型，首次翻译仍受网络、模型响应及语言包准备影响，不能保证零延迟。每人自备 Key、各自直连所选服务，没有应用方统一翻译队列；同组织或项目的 Key 仍可能共享服务商额度。

当前未公证测试版更新后可能需要重新授予屏幕录制及钥匙串权限。如开关已开却仍无法截图，请退出软件，移除旧录屏条目，再添加应用程序中的 ST专用.app。无需关闭系统整体安全保护。
