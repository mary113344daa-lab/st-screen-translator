# ST专用

macOS 截图翻译工具：按快捷键框选屏幕，将多语言文字翻译成简体中文，并在原图浮窗中查看。

## 下载

1.3.0 正在准备发布；发布页出现 ZIP 附件后即可下载。

[打开下载页面](https://github.com/mary113344daa-lab/st-screen-translator/releases)

支持 **macOS 15 及以上、Apple Silicon 和 Intel Mac**。下载发布附件中的 macOS ZIP，解压后将 `ST专用.app` 拖到“应用程序”，再打开。

当前 1.3.0 是**未经过 Apple Developer ID 签名和苹果公证的公开测试版**，macOS 可能阻止首次启动。发布正式公证版需要发布者取得相应证书。仅从此仓库下载并核对发布页中的文件信息；不需要关闭系统安全保护。

## 开始使用

1. 打开“翻译设置”。在线翻译可直接填写自己的 OpenAI Key，或配置其他兼容服务的地址、模型和 Key；也可以使用系统翻译。
2. 默认按 **F1** 截图，可在设置中任选 **F1–F8**，另有 Option + Shift + T。若按键触发亮度、音量等功能，请同时按 Fn，或在 macOS 键盘设置中启用标准功能键。
3. 首次截图按系统提示授予屏幕录制权限。框选后，译文会覆盖到截图对应位置。
4. 浮窗支持原图切换、置顶、重新截图、文字对照、复制图片和保存 PNG。Esc 关闭浮窗。

也可导入图片，或按 Command + Shift + V 粘贴图片/文字翻译。复杂表格、竖排、模糊小字建议分区域截图；复杂照片背景的覆盖效果可能留下色块。

## 自动更新

从 1.3.0 开始，软件默认每天检查一次更新，菜单栏和设置中也可手动检查。在设置中可开启“自动下载并安装更新”，或关闭自动检查。

更新订阅和安装包均进行签名校验。安装包只包含公开校验密钥。1.2 及更早的“译窗”需要手动安装一次新版本，以后沿用此更新频道。

## 数据与费用

- 截图在本机识别；在线翻译只将识别文字发送给用户配置的翻译服务，不上传截图。
- 每位用户自行填写密钥，密钥保存在自己的 macOS 钥匙串中。在线服务可能按使用量收费。
- 翻译历史仅在本次运行期间保存，退出后清除。
- 自动更新会连接 GitHub 检查版本及下载文件，已关闭系统画像上传。

翻译结果受截图清晰度、识别准确度和所选模型影响。重要内容请核对原文。
